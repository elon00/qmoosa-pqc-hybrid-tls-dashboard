Handshake & Record Layer State Machine

Step 1: ClientHello 1,216 B Wire
Client generates ephemeral X25519 keypair and ML-KEM-768 keypair. Bundles both public components into ClientKeyShare extension (group 0x11ec).
Step 2: ServerHello 1,120 B Wire
Server generates ephemeral X25519 keypair, computes ECDH secret, encapsulates ML-KEM ciphertext, and derives 64-byte combined shared secret.
Step 3: Symmetric Record Session AES-256-GCM
Client & Server derive traffic encryption keys and IVs using HKDF-SHA256. Every record uses IV masked by monotonic 64-bit sequence counter ($IV \oplus \text{seq\_num}$), preventing replay attacks.
